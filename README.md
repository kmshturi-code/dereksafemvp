# DerekSafe: Privacy-Preserving Anti-Fraud System

**DerekSafe** — это MVP-проект для хакатона, демонстрирующий использование Федеративного обучения (Federated Learning) для борьбы с финансовым мошенничеством без нарушения банковской тайны.

##  Проблема
Банки не могут обмениваться данными о мошенниках из-за законов о защите персональных данных. Из-за этого злоумышленник, заблокированный в Банке А, может беспрепятственно перевести украденные средства в Банк Б.

##  Решение
Мы используем архитектуру **Федеративного обучения**. Банки обучают локальные ИИ-модели на своих данных, не передавая их вовне. В центральный агрегатор отправляются только зашифрованные веса (weights) моделей. Агрегатор собирает их в единую глобальную модель (FedAvg) и возвращает банкам. 

Дополнительно используется **Дифференциальная конфиденциальность (Differential Privacy)** — добавление математического шума для полной защиты данных клиентов.

##  Как запустить локально
1. Установите зависимости:
   `pip install -r requirements.txt`
2. Запустите приложение:
   `streamlit run app.py`
3. Откройте в браузере `http://localhost:8501`

##  Функционал MVP
*   **Network Control:** Визуализация процесса обучения и синхронизации весов между банками.
*   **Transaction Monitor:** Симуляция атаки мошенника и блокировка транзакции на основе глобальной модели.
*   **Privacy Shield:** Демонстрация работы дифференциальной конфиденциальности (уровень шума).
